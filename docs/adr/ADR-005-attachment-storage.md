# ADR-005：附件存储

- 状态：接受
- 日期：2026-09-03

## 决策

MVP 二进制附件保存在服务端受控本地目录，数据库只保存元数据、随机存储键、MIME、大小、SHA-256、访问级别和作废状态。通过 `AttachmentStorage` 端口隔离实现，后续可替换对象存储。

## 原因

- 实训环境以简单、离线可复现为优先，无需先引入对象存储服务。
- 直接存数据库会增加备份与查询负担；直接暴露静态目录又绕过权限。

## 后果

- 附件只能通过鉴权下载接口访问；禁止把原文件名拼接成路径。
- 限制扩展名、MIME、大小，服务端重新命名，并记录哈希。
- 部署时必须挂载持久卷；备份需同时覆盖数据库和附件目录。
