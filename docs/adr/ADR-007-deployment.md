# ADR-007：部署拓扑

- 状态：接受
- 日期：2026-09-03

## 决策

开发与答辩基线使用 Docker Compose：反向代理/静态前端、Spring Boot 应用、MySQL 8.4、附件持久卷。服务端同时支持不使用 Docker 的本机 Maven 启动，便于课堂环境排障。

## 原因

- 单体拓扑能在 20 个工作日内复现，不引入 Kubernetes 或微服务运维成本。
- Compose 能锁定数据库版本、网络和卷，减少“只在某台电脑能跑”的问题。

## 后果

- 配置全部来自环境变量和 `.env.example`，真实 `.env` 不入库。
- 健康检查区分应用存活和数据库就绪；答辩前在干净环境完整演练。
- 若部署到学校服务器或云主机，沿用相同容器镜像和反向代理配置，不改变应用契约。
