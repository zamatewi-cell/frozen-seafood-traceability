# ADR-006：温度数据入口与规则判定

- 状态：接受
- 日期：2026-09-03

## 决策

P0 支持人工录入和内置模拟器；P1 支持 CSV 预校验后导入；真实设备接入仅保留接口边界。每条记录保存数据来源、业务测量时间、系统记录时间、环节、单位和判定规则版本。

## 原因

- 项目没有真实 IoT 设备或可信设备身份，不能把模拟数据宣传为实时采集。
- 按产品/任务/环节的版本化规则可避免把 `-18 ℃` 写死给不适用环节。

## 后果

- `SIMULATED/MANUAL/IMPORT` 在 UI 明确标识；只有真实接入且完成身份校验后才能使用 `DEVICE`。
- CSV 导入先返回逐行错误，用户确认后再事务入库。
- 历史温度结论绑定当时规则，规则更新不追溯改写历史结果。
