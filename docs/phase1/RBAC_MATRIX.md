# 角色权限与数据范围矩阵

## 1. 权限原则

- 默认拒绝；服务端同时校验角色、动作和数据范围。
- 系统管理员可管理全平台基础对象，但默认不修改企业业务记录。
- 企业操作员只能操作本组织拥有或通过有效交接关联的批次。
- 质量管理员可读取本组织及获授权关联链，并执行质量动作。
- 审计查看者只读；消费者只能访问独立公开接口。
- 对跨组织追溯使用“关系可见”规则，不因能看到图谱节点而获得附件或内部字段权限。

## 2. 动作矩阵

图例：`C/R/U` 为创建/读取/更新，`A` 为业务动作，`-` 为禁止。

| 资源/动作 | 系统管理员 | 企业操作员 | 质量管理员 | 审计查看者 | 消费者 |
|---|---|---|---|---|---|
| 组织/场所 C/R/U | 全平台 | R 本组织 | R 本组织 | R 授权范围 | - |
| 用户/角色 C/R/U | 全平台 | - | - | R 授权范围 | - |
| 产品/规则 C/R/U/发布 | 全平台 | R 有效版本 | R 有效版本 | R | - |
| 批次 C/R/U | R 全平台 | C/R/U 本组织草稿 | R 本组织及关联链 | R 授权链 | 公开摘要 R |
| 批次操作（拆/合/加工）C/A | - | C/A 本组织 | R | R | - |
| 追溯事件 C/R/更正 | R | C/R/更正本组织 | C/R/更正本组织质量事件 | R | 公开摘要 R |
| 交接 C/提交 | - | 本组织发起 | R | R | - |
| 交接 接受/拒绝 | - | 接收组织 | 接收组织质量员可代办 | R | - |
| 温度记录 C/R/导入 | R | C/R 本组织 | C/R 本组织及关联任务 | R | 摘要 R |
| 检测报告 C/R/审核 | R | C/R 草稿 | 审核/更正 | R 摘要 | 公开结论 R |
| 告警确认/处置 | R | R 本组织 | A 本组织及授权链 | R | - |
| 批次冻结/解冻 | R | - | A 本组织及授权链 | R | - |
| 模拟召回 C/A/关闭 | R | - | A 本组织及授权链 | R | 公开提示 R |
| 附件下载 | 按访问级别 | 本组织且有业务关联 | 本组织及授权链 | 受控只读 | 仅 `PUBLIC` |

| 导出 | 全平台且脱敏 | 本组织 | 本组织及授权链 | 授权范围且水印 | - |

## 3. 数据范围表达

| Scope | 含义 | 服务端过滤条件 |
|---|---|---|
| `PLATFORM` | 全平台管理 | 仅系统管理员；仍受业务动作限制 |
| `OWN_ORG` | 本组织 | `resource.org_id = principal.org_id` |
| `RELATED_CHAIN` | 本组织批次的授权上下游 | 谱系可达且存在有效业务关系/审计授权 |
| `EXPLICIT_GRANT` | 显式审计授权 | 授权未过期且包含资源/动作 |
| `PUBLIC_WHITELIST` | 消费者公开 | 只调用公开投影，禁止返回内部实体 |

## 4. 强制服务端检查

1. 每个企业接口从会话解析 `userId/orgId/roleIds`，不信任客户端传入组织 ID。
2. Mapper 查询必须显式携带组织/授权范围；禁止先查全表再在 Java 中过滤。
3. 更新语句同时检查资源版本与数据范围，更新行数为 0 时区分不存在、越权和并发冲突。
4. 谱系查询可返回相邻组织的公开业务节点，但内部备注、人员和附件需再次授权。
5. 所有拒绝访问记录请求 ID、用户、资源类型和动作，不记录敏感载荷。
