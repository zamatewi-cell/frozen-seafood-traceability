## 2. 主线 A：一张采购订单驱动的全链条（约 4 分钟）

### A1. 加工厂发起采购（买家 = plant_op）

1. 登录页点 **`plant_op`**（第 3 行），「登录」。
2. 左侧默认在 **「采购单」** tab。右上角点 **「发起采购」**。
3. 表单填写（照着选即可）：
   - 供货方：选 **蓝海远洋捕捞舰队**（供给捕捞原料）
   - 采购类型：**原料采购**
   - 商品：**南美白对虾**（或任一）

4. 点 **「提交采购单」**。
5. 预期：右上角弹出提示「采购单已提交，待供货方审批」，列表顶部出现一条 `PO` 开头的新单，状态 **SUBMITTED**。

7. 点右上角「退出」。

### A2. 捕捞船长审批（卖方 = capt_ship）

1. 登录 **`capt_ship`**（第 2 行）。
2. 「采购单」tab 里，能看到加工厂发来的单。此时这张单状态 **SUBMITTED**，右侧出现两个按钮 **「审批通过」「驳回」**。
3. 点 **「审批通过」** → 提示「操作成功」，状态变 **CONFIRMED**，按钮变成 **「按单排产」**。
   - 若想顺带演示**驳回**：先点「驳回」→ 弹出填写原因 → 「确认驳回」，状态变 REJECTED 并显示驳回原因；然后可按上述重新发一单再审批通过。
4. 口播：「捕捞船长确认接单，订单进入已确认状态。」
5. 退出。

### A3. 加工厂按单排产 → 生成加工批次（买方 plant_op 的确认与履约）

1. 再次登录 **`plant_op`**。
2. 「采购单」tab，找到刚才那张 CONFIRMED 的单，点 **「按单排产」**。
3. 预期：提示「已按单排产，生成加工批次」，切换到底部或其他位置能看到本次采购生成的**加工批次**。
   - 验证生成：去 **「批次/交接」** tab，列表里出现该批（香蕉色 `PROCESSING`/`ACTIVE` 状态）。
4. 口播：「买方确认后按单排产，系统自动为该采购落定一个加工批次——这是溯源账本的开始。」

### A4. 加工厂质检出证（plant_qa）

1. 登录 **`plant_qa`**（第 4 行）。
2. 顶部 tab 有 **「质量质检」**（还可能看到采购/批次），进入「质量质检」。
3. 左侧「本企业批次」点选刚生成的批次。
4. 点 **「对选中批次创建出厂质检」**，质检说明可选填。
5. 预期：右侧「质检记录」出现一条新质检单，结果状态 `INSPECTING`，下方出现 **「判定合格」「判定不合格」**。
6. 点 **「判定合格」** → 状态变 `PASS`。
7. 口播：「加工厂质检对批次出厂检验，判定合格放行。质检结果也会进入该批次的溯源履历。」

### A5. 交接发货 + 收货入库（加工厂 → 批发中心）

1. 登录 **`plant_op`**，进入 **「批次/交接」** tab。
2. 「交接单」区块点 **「发起交接」**：

4. 在新交接单里点 **「提交发货」** → 状态 `PENDING`，等接收方收货。
5. 口播：「加工厂把这批货交接给批发分装中心，发货信息记入溯源。」
6. 推出，登录 **`whl_op`**（批发开单员，第 5 行）。
7. 「批次/交接」tab 里，找到那条 `PENDING` 的交接单（接收方是自己组织时出现），点 **「收货入库」**。
8. 弹出「到货验收收货」：实收数量对得上可直接确认，数量不符可填差异原因。点 **「确认收货」** → 状态 `ACCEPTED`。
9. 口播：「批发中心验收收货，物流交接环节闭环，记录进入批次履历。」
10. 退出。

### A6. 电商/超市下单 → 自动生成溯源码（shop_op，**本次核心亮点**）

1. 登录 **`shop_op`**（第 7 行）。
2. 进入 **「销售单」** tab，点 **「发起销售」**：

### A7. 终端补记事件 + 聚合到码（演示"可随时补充"）

## 3. 支线 B：一码多批 + 多批次聚合（可单独演示，约 1 分钟）

适合作为"设计亮点"专门讲：

## 5. 讲解要点（给老师的「一句话口径」）

- **订单驱动**：终端下单 → 生成溯源码 → 反向拉动供应链（加工/捕捞）履约。
- **批次是账本**：一批货一份溯源记录，订单、交接、质检都落到相应批次上。
- **一码多批**：一个溯源码聚合多个批次，消费者扫码逐批查看。
- **自主补充**：中间环节可在码里随时补记（正在捕捞/正在加工/分装完成…），出货即完整。
- **真实可见性**：消费者看完整链路，中间角色只看自身及上游——本演示用界面范围体现，未做重权限隔离（教学合理边界）。

## 6. 常见踩坑 & 演示应急

| 现象 | 原因 / 处理 |
|---|---|
| 登录页空转登不进 | 密码是 `demo1234`；点账号色块自动填用户名 |
| 采购单看不到「审批通过」 | 该单的**买方是你自己**时才显示；换到「供货方」组织的账号登录 |
| 「按单排产」不可见 | 需要单处于 `CONFIRMED`，且当前账号是供货方（非买家） |
| 补记/聚合点击无反应 | 该时间点批次被限制（终态 RECALLED/CLOSED 不可补记）；换一批 ACTIVE/FROZEN 的批次操作 |
| 交接单不出现「收货入库」 | 需登录**接收方**组织账号 |
| 弹出校验报 400/422 | 多为某必填项缺失或幂等键过短；刷新后重试，幂等键由系统生成 |
| 扫码后是空时间线 | 该码还没绑定批次或没补记事件；先做 A6/A7 的绑定与补记 |
