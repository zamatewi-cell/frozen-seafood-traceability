# Phase 1 可交互原型

该目录是经确认视觉稿转化的交互原型，用于产品走查，不是生产 Vue 前端。

## 覆盖范围

- 批次追溯：搜索、错误码状态、节点下钻、数量平衡、分环节温控。
- 批次档案：合批构成、双时间戳、证据完整/待补。
- 流通与交接：以新建加工批次四步向导演示录入和关系校验。
- 质量事件：超温、影响范围与四步模拟召回处置。
- 消费者页面：有效码与模拟召回状态、公开字段和真实性声明。

## 本地运行

```bash
npm install
npm run dev
```

生产前端技术选型见 `docs/adr/ADR-003-vue-toolchain.md`。
